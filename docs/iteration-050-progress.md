# 2.60 · 自适应排列与一屏优先

日期：2026-09-30。版本 2.60，构建 260。

## 原则

按主界面实际可用宽高重新排列，而不是固定到某个显示器尺寸。优先使用横向空间、缩小装饰性标题与留白，尽可能把常用信息放在同一屏中；空间不足时保留必要滚动，不裁掉字段、错误或操作。

传真页面、顶部隐私遮盖与外观按钮保持不变。没有修改后端、设备指令、业务 API、权限、用户设置或原有展开状态。

## 实际调整

- 新增 `WorkspaceViewport`，区分正常、较短及很短的可用高度，统一页边距、卡片内边距、间距与列数边界；非传真详情通过容器获得实时尺寸，传真完全跳过该容器。
- 模块按宽度切为单列、两条或三条独立轨道，避免卡片之间被不等高内容制造大片空白。读卡器与 Wi-Fi Calling 更早并排，大窗口不再被固定页面最大宽度限制。
- 活动按宽度使用一、二或四列，短高度减少指标及标题留白；关于页在短窗口也可并排更新和许可证；诊断按宽度网格化，设置窗口测量自身可用尺寸。
- 通话页固定页面头，拨号与检查信息独立排列；接听、拨号按键、挂断按钮可换行，长设备名称改为直接选择的两行按钮，不增加点击步骤。
- 短信保留固定页面骨架，只在会话/消息区域内部滚动。
- Reader 技术身份在原有展开区内网格化；Profile 列表测量实际高度，短列表不再靠每行估算制造无必要滚动，长列表只在局部滚动。
- eSIM 下载表单与操作栏分离，提交、进度和结果固定在操作栏上方；长诊断内部滚动，阶段、错误码、失败原因不删减。
- 窄列中的模块网络按钮可换行，流量指标网格化；取消几个错误信息的行数裁切，完整错误必要时通过滚动读取。

## 修改范围

新增：`app/Sources/WorkspaceViewport.swift`、`app/Tests/WorkspaceViewport/main.swift`、`scripts/test-workspace-viewport.sh`。

调整：`ContentView`、`GlassComponents`、`HomeView`、`HomeSupportViews`、`ActivityView`、`AboutView`、`DiagnosticsView`、`SettingsView`、`ReaderCardView`、下载/通知/重命名/模块 eSIM 弹窗、`SMSView` 与消息子视图、`CallView` 与键盘/记录/布局支持视图。另更新渲染回归脚本、测试、设计规范、工程与版本元数据。

## 验证

- 视口密度、列数边界、极大/非法尺寸安全回退测试通过。
- 本机渲染测试通过：实际尺寸注入、短窗口标题收紧、传真隔离及顶部两个按钮在浅/深环境下保持原绘制。
- 主窗口关闭隐藏、重开、设置窗口隔离及最小化恢复回归通过。
- Reader eSIM 身份 8 组、BLE 手动选择 13 例通过。
- 全量 Swift 类型检查通过；随后交叉审阅修正了通话窄列和下载状态布局，最终以完整 Release 构建复核最终源码。
- 三路交叉审阅完成，无已知本轮新增阻塞问题；语法与 whitespace 检查通过。
- 传真四个文件及共享 Logo 预览资源的 SHA-256 与 2.59 改造前基线相同。
- 最终 macOS 27 / arm64 / 完整传真 Release 构建通过，DMG 校验通过；项目与桌面归档的 SHA-256 相同。

## 验收边界

“一屏优先”不是承诺任意窗口尺寸、任意数量记录和任意长度错误都无需滚动。极短窗口、较多 Profile/日志、长诊断仍需局部或页面滚动，所有内容与操作保持可达。

本轮没有重新测试真实 SIM 下载、VoWiFi 注册、来电/外呼、短信和传真收发，也没有重新启动硬件或修改代理/NAS。具体设备状态及完整应用窗口的手动验收仍由实际使用确认，不能把布局回归当成业务测试通过。
